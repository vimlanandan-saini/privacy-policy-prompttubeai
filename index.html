We automatically collect the following information when you use the App:

  • Usage Analytics:

  • Content Interaction:
    • Prompts you've viewed, copied, or favorited
    • Categories you frequently access
    • Images uploaded for AI prompt generation
    • Your generated prompts and preferences

  • Images You Upload: Photos selected from your device gallery for AI-based prompt generation

1.4 Location Information

3. Third-Party Services We Use

PromptTube AI integrates the following third-party services that collect and process data:

3.1 Firebase (Google LLC)

  • Firebase Authentication: User login and account management
  • Firebase Firestore: Real-time database for user data, prompts, categories, and favorites
  • Firebase Storage: Image storage for uploaded content and prompt screenshots
  • Firebase Analytics: App usage analytics and user behavior tracking
  • Firebase Crashlytics: Crash reporting and error tracking
  • Privacy Policy: https://firebase.google.com/support/privacy

3.2 Google Play Services

  • Google Play Billing: In-app subscription purchases and payment processing
  • Google Play In-App Review: Collect user ratings and reviews
  • Privacy Policy: https://policies.google.com/privacy

3.3 Google AdMob

  • Purpose: Display banner ads and rewarded video ads to free users
  • Data Collected: Device identifiers, ad interaction data, app usage patterns
  • Privacy Policy: https://policies.google.com/privacy
  • Ad Preferences: https://adssettings.google.com

3.4 Coil Image Loading Library

  • Purpose: Efficiently load and cache images from Firebase Storage
  • Data Processed: Image URLs, cached image files
  • Privacy: No personal data is sent to Coil; all image URLs are from Firebase

3.5 OkHttp

  • Purpose: HTTP client for network requests to Firebase and image loading
  • Data Processed: Network request metadata

4. Data Storage and Security

4.1 Data Storage Location

  • All user data is stored on Google Cloud Firebase servers
  • Data centers are located in regions compliant with GDPR and other privacy regulations
  • Images are stored in Firebase Storage with secure access controls

4.2 Security Measures

  • Password Encryption: Passwords are hashed using SHA-256 with unique salt values before storage
  • Firebase Security Rules: Database access is restricted to authenticated users only
  • HTTPS Encryption: All data transmission uses TLS/SSL encryption
  • Purchase Token Verification: Google Play subscriptions are verified server-side to prevent fraud
  • Session Management: User sessions are securely managed with Firebase Authentication tokens

4.3 Data Retention

  • Active Accounts: Data is retained as long as your account remains active
  • Inactive Accounts: Accounts inactive for 2+ years may be archived
  • Deleted Accounts: Upon account deletion, your data is permanently removed within 30 days
  • Subscription Records: Transaction history is retained for 7 years for legal compliance
  • Analytics Data: Aggregated analytics data may be retained indefinitely for service improvement
